## Publish on GitHub Pages
1. Create a public repo named `<github-username>.github.io`.
2. Upload `index.html`, `Shivakumar_Thota_AI_QA_Lead_Resume.pdf` and the `assets` folder to the repo root.
3. Settings > Pages > Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
4. The site is live at `https://<github-username>.github.io/` in a minute or two.

To update the resume, replace the PDF with a new file of the same name.
